# Antigravity Superengineering Operating System Skill

To execute any autonomous engineering mission:
1. Run `.agents/bin/agent-commander <command> "<objective>"` (e.g. `fix`, `debug`, `finish`, `test`, `audit`, `security`, `status`, `resume`).
2. Utilize tiered context loading (L0: Metadata, L1: Architecture, L2: Subsystem, L3: Exact code, L4: History).
3. Check Failure Memory via `.agents/bin/agent-commander memory "<symptom>"` before beginning root cause analysis.
4. Auto-repair defects following the 8-step loop (Observe -> Reproduce -> Trace -> Isolate -> Hypothesize -> Patch -> Test -> Regression Test) within a 3-attempt budget.
